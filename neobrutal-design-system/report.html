五条铁律

  • 色即语义。不为好看上色;一个颜色一旦有了含义,别处不得再用。
  • 黄只给人。批准、确认、可执行:黄色是人的签名,算法永远拿不到。
  • 紫只给身体。#A66BC2 是网页与 App 的共同契约(TaskMapUI.body),身体信号有专名。
  • 边界不作伪。3px 墨边、硬投影、无渐变无发光;物有其形,影是实的。
  • 章是仪式。确认要盖章,虚构要标注,拦下要说明:承认是一个动作,不是默认。

为什么是这一套

风格即产品个性

DaoBrew 卖的东西就一句话:安静的底,少而真的信号。这套语言把主张做成了可看见的制度:颜色即宣称,盖章才算数,黄章只属于人的批准。它不是审美偏好,是产品性格的直译:这是 DaoBrew 的整体设计语言,之后的 B2B 版本同样沿用。

Founder 的道家底色

纸是素底,一切色从素上生起;墨线是戒,边界清楚、不含糊、不假光晕;色即语义,无妄色,是一种少欲;章是仪式,承认是动作不是默认。素、戒、少欲、不作伪:这不是给页面找的修辞,是 founder 本来的工作方式,产品只是长成了同一个样子。贯穿的波与弦:如涛波依水。

任务管理,本来就该宁静

效率工具的默认美学在制造紧迫感:密度、红点、徽章、闪烁的未读数。我们反着来:底色安静,一屏只有一两个饱和信号,注意力自然落在有语义的地方。紫只给身体,黄只给人,大面积留白=一屏一念。用户的感受应该是:世界没有变少,但吵的东西没了。

几个分别

与通行新粗野的分别

通行版本用荧光大色块铺底、贴纸当装饰、噪音当态度。我们:素纸底、色即语义、章即制度、粗边只画在有边界的地方。一般的新粗野在喊,我们的在盖章。

与模糊渐变路线的分别

毛玻璃、大颗粒模糊、极光渐变传达的是「梦幻的智能」:边界被光晕溶解,层级靠氛围托着。三个问题:层级靠光晕就无法承诺语义;AI 产品用它太多,已经同质化;它和「证据、回执、盖章」的产品性格正好相反。渐变说「相信氛围」,墨线说「看证据」。

与效率工具默认美学的分别

好处落在三处:打开成本低(安静的底让人敢打开它,而不是先深呼吸);信号可信(颜色被铁律锁死,看到黄就知道是人批的,看到紫就知道是身体);风格可被用户描述(「那个像盖章一样的任务应用」是品牌资产,通用 SaaS 模板给不了,而且能直接带进 B2B)。

border: 3px solid var(--ink);          /* 卡片 3px,小件 2-2.5px */
shadow: 6px 6px 0 var(--ink);          /* 大件 6px,小件 3px,零羽化 */
radius: 12px;                          /* 小件 8-10px,一套到底 */
rotate: ±1° ~ ±3°;                     /* 只给贴纸与图章,正文不转 */
type:   一族三声(2026-08-18 定稿,与 daobrew.ai 一致)
        family = "SF Mono",ui-monospace,Menlo,Consolas
        CJK fallback = "PingFang SC"(只补中文字形,不是第二套视觉字体)
        显 = mono 700 大字号,一屏一声
        述 = mono 400 成段叙述,名称与结论用 700
        印 = mono 700 小字号 + 大写 + 字距,用于控件、链接、数据、公式、状态、免责
        判断法:字号是音量,字重是力度,字距是仪式;不靠换字体分层
        mono 偏宽:大字号整体降半档,关键复合词不许断行

Do

  • 大面积纸底 + 小面积语义色
  • 状态用图章表达(通过 / 拦下 / 已确认)
  • 硬投影表示「可按」「在场」
  • 空状态也用卡片认真排(说清为什么是空)
  • 显、述、印共用同一 mono 字族,只用字号、字重、字距分层
  • PingFang SC 只在缺字时补中文 glyph,不另立「中文字体」

Don't

  • 渐变、发光、毛玻璃、阴影羽化
  • 把黄色用在任何非人为批准的地方
  • 紫色挪作他用(它属于身体)
  • 荧光大色块铺底(那是另一派新粗野)
  • 正文倾斜、超过 ±3° 的旋转
  • 为标题、正文、控件另配 sans、楷体或 serif
