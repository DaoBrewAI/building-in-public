五条铁律

  • 色即语义。不为好看上色;一个颜色一旦有了含义,别处不得再用。
  • 黄只给人。批准、确认、可执行:黄色是人的签名,算法永远拿不到。
  • 紫只给身体。#A66BC2 是网页与 App 的共同契约(TaskMapUI.body),身体信号有专名。
  • 边界不作伪。3px 墨边、硬投影、无渐变无发光;物有其形,影是实的。
  • 章是仪式。确认要盖章,虚构要标注,拦下要说明:承认是一个动作,不是默认。

为什么是这一套

为什么适合 founder

founder 的整场叙事讲的就是「系统敢盖什么章」:这套语言把主张变成视觉制度,颜色即宣称,盖章才算数。贴纸的微旋转、大问号、÷10 又留住即兴与顽皮:严谨的规则 + 顽皮的手感,与 founder 台上的讲述是同一个气质。

为什么合「道」、有禅意

纸是素底,一切色从素上生起,如念头从静中生起;墨线是戒,边界清楚、不含糊、不假光晕;色即语义,无妄色,是一种少欲;章是仪式,承认是动作;贯穿的波与弦:如涛波依水。

为什么配唯识、配一个宁静的任务管理产品

这套配色本身就是产品主张的现场示范:底色安静,一屏只有一两个饱和信号,注意力自然落在有语义的地方。紫只给身体=前五识有专名;黄只给人=批准权不外包;大面积留白=一屏一念。用户的感受应该是:世界没有变少,但吵的东西没了。

border: 3px solid var(--ink);          /* 卡片 3px,小件 2-2.5px */
shadow: 6px 6px 0 var(--ink);          /* 大件 6px,小件 3px,零羽化 */
radius: 12px;                          /* 小件 8-10px,一套到底 */
rotate: ±1° ~ ±3°;                     /* 只给贴纸与图章,正文不转 */
type:   PingFang 700 大标题 / 楷体只给经文与落款 / mono 只给数据

Do

  • 大面积纸底 + 小面积语义色
  • 状态用图章表达(通过 / 拦下 / 已确认)
  • 硬投影表示「可按」「在场」
  • 空状态也用卡片认真排(说清为什么是空)
  • 数据一律 mono,标题一律加粗

Don't

  • 渐变、发光、毛玻璃、阴影羽化
  • 把黄色用在任何非人为批准的地方
  • 紫色挪作他用(它属于身体)
  • 荧光大色块铺底(那是另一派新粗野)
  • 正文倾斜、超过 ±3° 的旋转
