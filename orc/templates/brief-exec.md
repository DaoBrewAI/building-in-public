# 执行规则：mission {{MISSION}}

这份文件和设计、计划、DAG 一起冻结并由用户签名。每个执行会话开始时都会读到它。

- 你只做分配给你的那一个节点：只改这个节点 `files` 里列出的文件，达到它的 `acceptance`。
- 你的 git 是只读的。每完成一条验收标准，就按 orc 给你的方式提交一次提交请求，由 commit broker 代为提交；不要试图自己 `git commit`。
- 每次提交前都会有对齐评审，对照 NORTHSTAR、签名的设计和你这个节点的条目。收到纠偏单时，按纠偏单改，不要改测试或检查来让评审通过。
- 设计、计划、DAG 已经冻结。你认为它们需要改时，在输出里写明理由，然后停止，由用户决定。
- 不要读写你的 worktree 之外的文件，不要访问未放行的网络地址。
