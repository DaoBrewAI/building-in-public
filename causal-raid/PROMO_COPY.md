## 小红书

标题：我把 DaoBrew 做成了一场一分钟 Boss Raid

这周我把 DaoBrew 的 Causal Task Manager 做成了一场能玩的水墨 Boss Raid。

打开链接就进战场。不登录，也不用装客户端。

玩家先打掉三个会反复出现的症状，拿到因果证据。证据闭合后，根因候选变成 Boss。

Boss 倒下会爆五件装备：Goal、Steps、Acceptance、Permission、Route。

装备集齐，玩家确认一次权限。纸 Agent 会自己穿过 WebGL、Runtime、Browser 三个执行节点，一直跑到 Artifact 回到场景里。

最后停在「已处理 · 等待验证」。这一轮执行完成了，根因还要等下一次同类事件确认。
